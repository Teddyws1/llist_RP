# llist_Roleplay

Site criado para facilitar a busca de comandos de animações do GTA V RP.

🔗 Acesse: https://teddyws1.github.io/llist_RP/

## 📌 Sobre o projeto

O **llist_Roleplay** ajuda jogadores de GTA V RP a encontrar comandos de animações de forma rápida e prática.

## ⚙️ Funcionalidades

- Busca por nome ou ID
- Sistema de tema claro e escuro
- Sistema de favoritos
- Botão de copiar comando pronto
- Modal automático de resultado
- Área de atualizações
- Interface simples e rápida
- e outros tipos de sistemas
- e sistema específicos

## 🚀 Exemplo

Ao copiar o comando **deitar**, o sistema copia automaticamente:

*/e deitar*
